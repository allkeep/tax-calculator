工资个税计算器

支持单月税前正算、税后反推，以及全年累计测算。

五险一金、专项附加扣除和其他扣除都可以按你的实际口径调整。

导入 Excel（可选） 未导入文件

支持本地 `.xls / .xlsx / .xlsm / .xlsb`。导入后可以按“工作表 + 员工记录”选择，并自动回填当前月和累计参数。

选择 Excel 后，这里会显示识别到的工作表、员工人数和字段匹配情况。

单月计算

先选择输入口径，再输入本月金额。税后模式用于反推税前，税前模式用于正算当月个税和到手工资。

输入本月税前工资后，工具会直接计算本期个税和税后工资。

本期参数

社保与公积金支持“金额 / 比例 / 基数”联动。你可以直接填金额，也可以填比例和基数；如果手填金额，工具会自动反算比例。

如商业健康保险、税延养老保险等依法确定的其他扣除。
可手填，也可由社保公积金自动汇总。
社保公积金联动：社保基数会同时作用于养老、医疗、失业；公积金基数单独计算。比例按百分数填写，例如 `8` 表示 `8%`。

截至上月累计

这些值填“截至上月”为止的累计数。如果你手上只有本月申报表，通常可以用“本月累计值 - 本月对应值”反推出来。

按本月计算结果自动更新，口径为本年累计个税 / 本年累计收入。

填表小提示

如果你是从《综合所得申报税款计算》那张表抄数，通常可以这么整理：

  • 上期累计收入 = 当前行“累计收入额” - 本期收入
  • 上期累计专项扣除 = 当前行“累计专项扣除” - 本期养老/医疗/失业/公积金/年金
  • 上期累计专项附加扣除 = 当前行各项专项附加扣除累计合计 - 本期专项附加扣除
  • 上期累计已预扣税额 = 当前行“已缴税额”

# 工资个税计算器（中国居民个人综合所得预扣预缴测算工具）

一个基于纯前端（原生 HTML / CSS / JavaScript）实现的中国居民个人工资、薪金所得个人所得税计算器。无需后端服务，打开浏览器即可离线使用；所有数据均在本地浏览器中处理，不上传任何服务器。

---

## 功能特性

- **单月计算（正算 & 反推）**
  - **税前工资正算**：输入当月税前工资及各项扣除，计算本期应扣个税、税后到手工资、累计应纳税所得额、适用预扣率、速算扣除数及本年综合税负。
  - **税后工资反推**：输入目标到手工资，基于整数“分”与二分查找算法反推满足条件（不低于目标到手）的最小税前工资。
  - **五险一金联动**：支持社保基数（联动养老、医疗、失业）与公积金基数（单独计算），金额与个人比例（`%`）可双向自动换算；也可直接手动填写“本期专项扣除合计”。
  - **支持截至上月累计参数**：支持录入上期累计收入、累计免税收入、累计减除费用、累计专项扣除、累计专项附加扣除、累计其他扣除、累计减免税额及已预扣税额。
- **全年累计测算（1–12 月）**
  - 支持 **统一税前收入**（正算）与 **统一到手目标**（反推）两种口径批量填充，填充后仍支持逐月单独微调。
  - 支持 **精简模式**（直接填专项扣除合计）与 **详细模式**（分别填写养老、医疗、失业、公积金或通过基数与比例折算）。
  - 按 1 月至 12 月依次滚动累计预扣预缴，自动计算全年税前收入、全年个税、全年到手、全年综合税负等汇总指标，并自动隐藏未填值的零值可选列。
- **本地 Excel 工资表导入回填**
  - 基于 [SheetJS (`xlsx.full.min.js`)](https://sheetjs.com/) 在本地解析 `.xls` / `.xlsx` / `.xlsm` / `.xlsb` 文件。
  - 自动识别包含 `姓名` 和 `本期收入` 表头的工作表，按“工作表 + 员工记录”一键回填至单月计算面板。
- **可折叠分区界面**
  - “本期参数”、“截至上月累计”、“单月结果”、“全年批量设置”、“逐月计算”、“年度汇总”均支持折叠/展开，界面清爽直观。

## 快速开始

### 方式一：本地直接打开

1. 克隆或下载本仓库到本地。
2. 直接双击打开 [`index.html`](index.html) 即可在现代浏览器中运行。

> 若需使用 Excel 导入功能，请确保 `vendor/xlsx.full.min.js` 与 `index.html` 的相对路径 `./vendor/xlsx.full.min.js` 保持完整。

### 方式二：通过本地静态服务器或 GitHub Pages 访问

可在项目根目录启动任意静态文件服务器，例如：

```bash
# Python 3
python -m http.server 8080
```

随后访问 `http://localhost:8080`。本项目为纯静态站点，上传至 GitHub 后也可直接在仓库 **Settings -> Pages** 中选择主分支根目录一键发布为在线工具。

## 使用说明

### 1. 单月计算

1. 选择 **当前月份**（1–12）与 **输入口径**（`税前工资` / `税后工资`）。
2. 输入对应金额后点击 **计算个税**（或 **反推税前**）。
3. 在 **本期参数** 中调整免税收入、减除费用（默认 `5000.00` 元）、专项附加扣除、其他税前扣除及五险一金：
   - 默认预置参考社保基数 `4504.00`，个人比例默认养老 `8%`、医疗 `2%`、失业 `0.3%`（可在页面内自由修改或清空）。
   - 修改基数或比例会自动重算金额；手填金额时若有基数会自动反算比例。
4. 如需跨月连续测算，可在 **截至上月累计** 中填写截至上月末的累计收入、累计扣除与已预扣税额。

### 2. 全年测算

1. 切换到 **全年测算** 标签页。
2. 在 **全年批量设置** 中选择：
   - **统一输入口径**：`统一税前收入` 或 `统一到手目标`
   - **专项扣除填写方式**：`精简模式`（填写总额）或 `详细模式`（分项及基数比例折算）
3. 填好统一参数后点击 **计算全年**，随后可在下方 **逐月计算** 中针对特定月份（如年终奖、调薪月等）单独修改后查看实时结果。

### 3. Excel 工资税表导入

1. 展开单月面板顶部的 **导入 Excel（可选）**。
2. 选择本地导出的工资薪金税款计算表（支持 `.xls / .xlsx / .xlsm / .xlsb`）。
3. 工具会扫描同时包含 **`姓名`** 与 **`本期收入`** 列名的表头行，自动识别下列字段并反推“截至上月累计”参数：
   - **当期字段**：`本期收入`、`本期免税收入`、`本期基本养老保险费`、`本期基本医疗保险费`、`本期失业保险费`、`本期住房公积金`、`本期企业(职业)年金` / `本期企业年金`
   - **累计字段**：`累计收入额`、`累计免税收入`、`累计减除费用`、`累计专项扣除`、`累计减免税额`、`已缴税额`
   - **专项附加扣除累计列**：`累计子女教育支出扣除`、`累计继续教育支出扣除`、`累计住房贷款利息支出扣除`、`累计住房租金支出扣除`、`累计赡养老人支出扣除`、`累计3岁以下婴幼儿照护`
   - **其他扣除累计列**：`累计个人养老金`、`累计其他扣除`、`累计准予扣除的捐赠`
   - **所属期识别**：从 `税款所属期止` 或 `税款所属期起` 解析月份；对于仅提供累计值的专项附加扣除/其他扣除，会按所属月份平均拆分到当月，非均匀发生时可在导入后手动微调。

## 税率与计算规则

本项目所有金额内部均转换为 **整数“分”** 进行计算，避免浮点数精度误差，并采用《个人所得税预扣率表一（居民个人工资、薪金所得预扣预缴适用）》：

| 级数 | 累计预扣预缴应纳税所得额（元） | 预扣率 | 速算扣除数（元） |
| :---: | :--- | :---: | :---: |
| 1 | 不超过 36,000 | 3% | 0 |
| 2 | 超过 36,000 至 144,000 | 10% | 2,520 |
| 3 | 超过 144,000 至 300,000 | 20% | 16,920 |
| 4 | 超过 300,000 至 420,000 | 25% | 31,920 |
| 5 | 超过 420,000 至 660,000 | 30% | 52,920 |
| 6 | 超过 660,000 至 960,000 | 35% | 85,920 |
| 7 | 超过 960,000 | 45% | 181,920 |

核心计算公式：

- **累计应纳税所得额** = 累计收入 − 累计免税收入 − 累计减除费用 − 累计专项扣除 − 累计专项附加扣除 − 累计依法确定的其他扣除
- **本期应预扣预缴税额** = `max(0, 累计应纳税所得额 × 预扣率 − 速算扣除数 − 累计减免税额 − 上期累计已预扣税额)`
- **本期税后到手工资** = 本期税前工资 + 本期免税收入 − 本期专项扣除（及直接扣款）− 本期个税
- **税后反推税前**：由于累计预扣法在税率跳档及分位四舍五入处单调但非线性，工具采用二分查找求解满足 `到手工资 >= 目标税后工资` 的最小税前工资（精确到分）。

## 二次开发与维护指南

| 文件 | 职责 | 修改建议 |
| :--- | :--- | :--- |
| `index.html` | 页面结构、模块顺序与静态文案 | 调整模块顺序、字段排布或文案时优先修改此文件 |
| `styles.css` | 主题颜色、间距、响应式栅格与折叠样式 | 调整视觉风格、输入框尺寸与按钮样式时修改此文件 |
| `app.js` | 表单绑定、税额计算、反推算法与 Excel 解析 | 修改税率表、默认社保基数比例或字段映射规则时修改此文件 |
| `vendor/xlsx.full.min.js` | SheetJS Excel 解析依赖 | 勿随意修改文件名或目录层级 |

> **开发注意**：[`app.js`](app.js) 依赖 [`index.html`](index.html) 中控件的 `id` 与 `data-*` 属性读取输入和渲染结果，调整 HTML 结构时请保留原有 `id` 与 `data-*` 属性。每次修改建议回归测试：**单月税前正算**、**单月税后反推**、**全年测算**、**Excel 导入** 四项核心场景。
